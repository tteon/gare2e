Graph 관측 연결·수집 범위

생성 요청 종류별 출력 토큰

tool_calls는 해당 LLM 응답의 전체 출력입니다. Cypher 인자만의 토큰 수나 reasoning 분량을 의미하지 않습니다. Context 구성은 기록된 경우 UTF-8 bytes로 표시합니다. 구성별 토큰은 미측정입니다.

2 · Runtime Performance Characterization

공통 측정 구간의 서버 상태

Replica별 관측 (수집된 조건)

TTFT는 queue/prefill과 겹칩니다. 요청별 decode 시간을 합산한 값은 GPU 독점 시간이 아닙니다. Running request는 실제 decode sequence 수가 아닙니다.
