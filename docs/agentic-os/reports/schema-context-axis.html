2 · Why the control matters

What C- rules out

Two cheap explanations for S1's gain would have been "more tokens make the model careful" and "any structured preamble helps". C- has S1's exact token count and a structured shape, but names labels that do not exist. The agent believed it: missing_grbench_node_label was raised 206 times in 90 cases, repairs climbed to 3.6–3.9 per case and answers fell to 0 / 2 / 1. The slice's content is what the model uses.

Where the gain comes from

S1 cases validate at the same rate as B0 (29–30 / 30) but reach a non-empty result more often and stop earlier: repairs 0.13–0.37 per case (B0 0.6–1.0), exhaustion 1–9 / 30 in L1–L2 (B0 14–20). The slice removes the guess about which property carries the name or title — the anchor the static guard demands — so the first anchored query is usually right.

What S1 does not fix

Hard questions (argmax, collaborator-in-year, closest collaborator): 22 / 30 still run out the six-turn budget while holding rows. Finalisation, not retrieval, remains the L3 loss — the same reading as lab-s3 and lab-s13 at N = 30.

4 · What this settles for the schema story

  • Relevant × structural (S1) beats full × structural (B0) on Cypher, and the control shows it is the slice's content. On this graph the "full" physical schema is the smaller context (62 vs 160 tokens), so the token-cost argument for relevant schemas does not apply here; the argument is correctness of the anchor.
  • Ontology enrichment (S4) has no measurable effect where it exists (SPARQL), and it does not exist yet for Cypher. The two missing 2×2 cells — GRBench relevant × ontology and full × ontology on both graphs — are the next arms to build (request 016); the honest expectation from this data is a small or null effect on top of S1.
  • Multi-agent lanes need the repair-loop fix before any schema arm can show evidence. Validation improved fourfold with S1 and evidence stayed at zero.
  • Serving is untouched by the arm (163–176 tok/s at K=8, decode share 0.82–0.90, host ≤ 0.02): the schema axis is a correctness axis, and can be studied at the cheapest admissible serving shape.
